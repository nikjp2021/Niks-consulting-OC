# Page Structure for Nik's Consulting Website

## Pages
1. Home (/) - Landing page with hero, services, case studies, process, testimonials, CTA
2. Services (/services) - Detailed view of all service offerings
3. Case Studies (/case-studies) - Detailed case studies with filtering capability
4. About (/about) - Company information, mission, team
5. Training (/training) - AI training programs
6. Gifted Internship (/gifted) - Information about gifted internship program
7. Contact (/contact) - Contact form and information
8. Get a Quote (/get-a-quote) - Quote request form
9. Blog (/blog) - Coming soon page

## Page Sections

### Home Page Sections
- Hero
- Statistics
- Services (overview)
- Case Studies (highlight)
- Process
- Testimonials
- Call to Action

### Services Page Sections
- Page Header
- Detailed breakdown of each service category with examples
- Service comparison table
- Call to Action

### Case Studies Page Sections
- Page Header
- Filterable case studies grid (by industry, technology, results)
- Detailed case study view (accessible from grid)
- Call to Action

### About Page Sections
- Page Header
- Company story/mission
- Team introduction
- Values and approach
- Call to Action

### Training Page Sections
- Page Header
- Training program overview
- Curriculum details
- Instructor information
- Enrollment information
- Testimonials
- Call to Action

### Gifted Internship Page Sections
- Page Header
- Program description
- Benefits and learning outcomes
- Application process
- Past intern experiences
- Call to Action

### Contact Page Sections
- Page Header
- Contact form
- Office information
- Map location
- Social media links

### Get a Quote Page Sections
- Page Header
- Quote request form
- Service selection checklist
- Project details form
- Timeline and budget questions
- Submit button

### Blog Page Sections
- Page Header
- "Coming Soon" message
- Subscription form for blog updates
